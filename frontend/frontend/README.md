# Belay ROUTE OS - React + Vite Frontend

Interactive, modern Route Setting Operations Dashboard built with React 18, TypeScript, Tailwind CSS, and Lucide Icons.

## Requirements
- Node.js (v18 or higher)
- npm or yarn / pnpm

## Quick Start (Localhost via VS Code)

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Start Vite Development Server**:
   ```bash
   npm run dev
   ```

3. **Open in Browser**:
   Open `http://localhost:5173` (or the port displayed in terminal) in your browser.

## Build for Production

To generate static production assets:
```bash
npm run build
```
The output files will be in the `dist/` directory.
