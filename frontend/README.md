# 🧗 Belay Route OS — Frontend (Alpine Minimal Pro / 2026 Edition)

Nowoczesny, taktyczny system operacyjny dla ścian wspinaczkowych do zarządzania bazą dróg, rotacją boulderów, etykietami QR i pracą ekipy routesetterów.

## 🚀 Szybki start w VS Code (Localhost)

1. **Otwórz ten folder w VS Code** (`File -> Open Folder...`).
2. **Otwórz terminal wbudowany** (`Ctrl + ` ` lub `Terminal -> New Terminal`).
3. **Zainstaluj zależności**:
   ```bash
   npm install
   ```
4. **Uruchom serwer developerski Vite**:
   ```bash
   npm run dev
   ```
5. **Otwórz w przeglądarce**:
   Przejdź pod adres: `http://localhost:5173` (lub port wyświetlony w terminalu).

## 🎨 Nowy Wygląd 2026 (Alpine Minimal Pro)
- **Kolory**: Czysta baza Off-White (`#fafaf9`), wyraziste akcenty **International Orange** (`#ff4d00`), ciemne panele operacyjne `zinc-950`.
- **Typografia**: *Plus Jakarta Sans* dla interfejsu + *JetBrains Mono* dla danych technicznych, kodów i wycen.
- **Funkcje**:
  - Baza Dróg i Boulderów (filtry, wyceny francuskie & V-scale, statusy).
  - Generator i Drukarka Etykiet QR z symulatorem wspinacza.
  - Planer i Harmonogram Resetów Sektorów (cykl 45-dniowy).
  - Zadania Route Setterów (tablica Kanban).
  - Analityka i Statystyki Przejść (wykresy Recharts).
  - Podgląd architektury Django REST API.
